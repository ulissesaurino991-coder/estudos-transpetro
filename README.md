# 🥷 Reta Final Transpetro — Engenharia Química

Plataforma de estudos pessoal para o concurso **Transpetro / PSP / Terra 2026.4 — Engenharia Química (Ênfase 27)**, banca **Cesgranrio**. Prova: **06/12/2026**.

## O que tem aqui

- **Edital verticalizado** — os 99 tópicos do Anexo IV, com marcação de progresso (não vi / revisei / domino).
- **Banco de 470 questões reais** das 9 provas (2010–2023), com alternativas e gabarito, interativo.
- **Cronograma de reta final** dia a dia (37 dias): simulados Transpetro aos sábados, Petrobras nos dias úteis, 99 tópicos distribuídos e Português/Inglês do zero.
- **Refazer as 9 provas** com registro de status e nota.
- **Análise ninja por matéria** (como cada assunto caiu desde 2010) + padrões da banca.
- **Estratégia Ninja** (plano mestre) e **Diário de Erros**.

As 9 provas tabuladas: Petrobras 2010, 2011, 2012, 2014, 2018 · Transpetro 2011, 2012, 2018, 2023 (⭐ espelho).

## Como usar

- **Online (GitHub Pages):** abra o link de publicação do repositório.
- **Offline:** baixe `plataforma-transpetro.html` (arquivo único, autossuficiente) e abra no navegador.

Todo o progresso fica salvo no seu navegador (localStorage). Puro HTML + CSS + JavaScript, sem dependências.
